The Sales Desk gives each order one row, and a discount code wins over a link. So a social link used with a promoter's code counts under Promoters there, and the TikTok links sit under Ads.

An order counts here when its discount code or its link contains one of the five words. When both do, the discount code decides the group. Revenue is the order total less the discount.
